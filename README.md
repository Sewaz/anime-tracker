React Router

## Backend

Node.js
Express
TypeScript

## Planned

## Project Structure

client/ — frontend application

server/ — backend API

# Getting Started

1. Install frontend dependencies
cd client
npm install

2. Install backend dependencies
cd ../server
npm install

3. Configure environment
Create server/.env:
PORT=5000

4. Start backend
From server/: npm run dev

5. Start frontend
From client/: npm run dev
